# SmartCities
26-27 SmartCities

Ce projet est consacré à l'utilisation globale d'un Raspberry Pi Pico.

Pour ce faire, nous utiliserons différents types de composants.

Ils apparaîtront sous la forme d'une liste de liens :


## GPIO
- [GPIO](documentation/GPIO)

Ce répertoire concernera l'ensemble des LED simple, bouton-poussoir, interruption.




## AD-PWM 
lecture du potentiomètre, PWM (LED, musique, servo).


## LCD 
 documentation des fonctions de la librairie, affichage de la valeur du potentiomètre.

## LED_neo 
 utilisation des LEDs néopixel, documentation des fonctions de la librairie, arc-en-ciel.
sensors : température et humidité, luminosité, PIR.
network : Accès réseau avec le RPi Pico.
