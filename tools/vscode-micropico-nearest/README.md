# SmartCities: MicroPico nearest project

Avec un fichier Python actif, `F5` recherche le fichier `.micropico` le plus
proche dans ses dossiers parents, puis envoie ce projet avec MicroPico.

L’extension est locale au projet. Pour l’installer, empaquetez ce dossier en
VSIX, puis installez le fichier obtenu dans VS Code.
